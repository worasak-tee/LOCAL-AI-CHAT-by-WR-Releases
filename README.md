# LOCAL-AI-CHAT-by-WR — Windows Releases

Official Windows downloads for **LOCAL-AI-CHAT-by-WR**.

## Download

1. Open **Releases** on the right side of this page.
2. Open the latest **Stable** release.
3. Under **Assets**, download `LOCAL-AI-CHAT-by-WR_Portable.exe`.
4. Run the EXE directly — Python is not required.

## Release channels

- **Stable** — recommended for team/production use.
- **Pre-release / Dev** — testing builds only; do not deploy to normal users unless instructed.

## Portable app

The Windows Portable EXE includes its Python runtime and required application dependencies. Users should not run developer files such as `run.bat`.

## Security

This public repository contains release downloads only. Application source code remains in the private development repository.
